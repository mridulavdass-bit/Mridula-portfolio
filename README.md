# Mridula-portfolio

A tracker of work done at PayGlocal, organized by company/entry.

## Development

```bash
npm install
npm run dev
```

Runs at http://localhost:5173 with hot reload.

## Build

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript + Vite
- Tailwind CSS (mobile-first, responsive breakpoints, dark mode aware)

Work entries live in [src/data/work.ts](src/data/work.ts) — add new items there.
